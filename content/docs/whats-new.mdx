## Overview

Endvoyant v2.0.0 comes with a complete rewrite in Typescript, a revamped command structure, and new features focused on improving user experience and expanding functionality. Below is a summary of the most significant changes and additions in this release.

## New Features

- **Localization Support**: Endvoyant now supports all 14 languages available in Arknights: Endfield, allowing users to interact with the bot in their preferred language. This can be changed anytime with the `/settings` command.
- **Premium**: A one-time purchase that unlocks various features, including unlimited account linking, priority support, and early access to new features. Use the `/premium` command to view benefits and purchase.

## Optimizations and Improvements

- **Faster Response Times**: Utilizing undici and optimized database queries, Endvoyant now responds up to `{responseTimeImprovement}`% faster on average.
- **Improved Error Handling**: More robust error handling and logging, allowing for quicker identification and resolution of issues.
- **Enhanced Security**: Updated dependencies and security practices to ensure user data is protected.
- **Better Code Maintainability**: The complete rewrite in Typescript has improved code readability, maintainability, and scalability for future development.
- **Revamped Command Structure**: Commands have been reorganized for better discoverability and usability, with some commands renamed or consolidated.
