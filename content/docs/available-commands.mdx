## Command Overview

Endvoyant currently ships with the following slash commands for **Arknights: Endfield**.

| Command            | Linked account required | Purpose                                                            |
| ------------------ | ----------------------- | ------------------------------------------------------------------ |
| `/about`           | No                      | Info regarding Endvoyant                                           |
| `/add account`     | No                      | Link an Arknights: Endfield account                                |
| `/daily signin`    | Yes                     | Claim daily signin rewards                                         |
| `/export data`     | Yes                     | Download your data                                                 |
| `/full profile`    | Yes                     | View your full profile                                             |
| `/list codes`      | No                      | List available redemption codes                                    |
| `/manage accounts` | Yes                     | Manage your linked accounts                                        |
| `/premium`         | Yes                     | View/Purchase premium                                              |
| `/profile`         | Yes                     | View your profile information                                      |
| `/redeem`          | Yes                     | Redeem a redemption code                                           |
| `/settings`        | Yes                     | Manage privacy, language, notifications, and account-level toggles |
| `/umbral monument` | Yes                     | View your Umbral Monument data                                     |
